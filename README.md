# Hyouka Messages

Minimal Flutter Messages app designed for offline use.

## Features

- Pure black background.
- Local in-memory sample messages.
- Long-press any message to open Delete / Cancel confirmation.
- Select all messages, then delete them in one confirmation.
- No third-party runtime packages and no network data source.

## Android build

GitHub Actions generates the standard Flutter Android platform scaffold when needed, runs analysis and widget tests, and builds the release APK.
